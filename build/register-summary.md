# Routes demo register

A tiny demo register with one building block: a data model for routes.


Created from the [OGC building block template](https://github.com/opengeospatial/bblock-template)
to show how a new building block is defined, documented and tested. It reuses the OGC feature model.


## Building Blocks

### `ogc.demo.route` — Route

**Type:** schema

A route: a road or path, described as a feature with a length in metres and a line geometry.
